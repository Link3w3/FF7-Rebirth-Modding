End / FFVII Rebirth Asset Tools

Open the End project, then use Window > FFVII Rebirth Tools.

FFVII Rebirth Asset Tools
  Search 406 notify class profiles, 323 skeleton records, and 770 observed
  effect parameter profiles from the supplied UAssetGUI archive.
  Select an authored animation in the Content Browser and press Use selected
  sequence. Choose a notify class, time and duration, then Add catalog notify.
  Edit the native properties in the panel. Changes support Undo/Redo.
  Pin a target sequence, select a different source sequence, then Copy notifies
  to copy native notify objects and their original timing and state durations.
  Select an authored EndAnimSet and press Use selected EndAnimSet; then select
  animation assets and add their named references. Duplicate keys are refused.
  The tools leave asset changes unsaved until you save them yourself.

UAssetGUI Cooked Package Tools
  Opens the exact original application from UAssetGUI 2.0 - qol changes.zip.
  Use its original package, mapping, notify, row, effect-parameter and animation
  tools for cooked-file workflows. Microsoft Windows Desktop Runtime 8 is
  required. The application does not receive an asset path automatically.

Native editing requires authored assets. Cooked originals can be inspected or
used as copy sources, but these tools do not edit them in place. EndAnimSet
reference editing does not prove retail package dependencies or game behavior.
Skeleton catalog entries are topology references, not interchangeable rigs.

This editor-only plugin also registers three missing SQEX viewport commands
that prevented the unmodified End editor viewport from starting normally.
It contains no retail animation hooks or skeleton compatibility runtime DLL.

Licenses and original third-party notices are retained beside the catalogs
and the bundled application. This plugin targets the tested End/RebirthV5
editor build; it is not an update for the earlier Tres engine.
